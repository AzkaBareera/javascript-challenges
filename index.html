JavaScript Assignment

Web Interface Design

1. Age to Days Converter

Enter your age in years to see it converted to days.

2. Hours to Seconds Converter

Enter a number of hours to see it converted to seconds.

3. Find the Next Number

Scenario A: find the number that comes right after a chosen number inside an array.
Scenario B: type any single number (integer or float) and get the next one.

Scenario A — Array based
Scenario B — Single value

4. Capitalize Name

Enter your name in lowercase only. The first letter will be capitalized automatically.

5. BMI Calculator

Enter weight (kg) and height (m) to calculate Body Mass Index.

6. Random Array — First & Last Element

Generates a random array of numbers, then picks the first and last elements.

7. Add Two Numbers (Event Handling)

Type a number in the first box. Result shows NaN until the second box also has a value — then it shows the sum live.
